# Component cookbook — Bootstrap 5 for HTML reports

Every report gets Bootstrap 5 (inlined by default via `build_head()`), so these
components are free — write classes, not CSS. Theme is controlled by
`<html data-bs-theme="dark|light">`; set it once in `build_head(theme=...)`
and every component follows.

## Page skeleton (canonical report structure)

Follow the chat-analyzer report convention — readers know where to look:

1. `<h1>` + `.subtitle` — what, where, when
2. `Outcomes` — computed headline numbers in stat cards
3. Charts and per-period tables
4. `Findings & Caveats` — always state confounds
5. Verdict box
6. `Appendix — Methodology & Config` (optional)
7. Footer

```python
from html_lib import build_head, build_foot, section_heading

html = [build_head("My Report")]           # <head> + container open
html.append('<h1 class="mb-1">My Report</h1>')
html.append('<p class="subtitle">Context: endpoint, window, builds</p>')
# ... sections ...
html.append(build_foot("Generated by my_report.py · data sources"))
```

## Stat cards

```python
from html_lib import stat_cards_row

stat_cards_row([
    ("Throughput", "326.1", "req/s @ 120 conc", "#58a6ff"),
    ("TTFT p50", "357ms", "3.2x lower than baseline", "#3fb950"),
    ("Errors", "0", "across 9 tests", "#d29922"),
])
```
Emits `row row-cols-1 row-cols-md-{n} g-3` with a `.card` per item; `accent`
adds a colored left border. Values use tabular numerals.

## Tables

```python
from html_lib import table_html

table_html(
    ["Period", "Current", "Baseline", "Change"],
    [["W1", "120.4", "98.2", "+23%"], ...],
    caption="Optional caption",
    row_classes=["", "table-success"],   # winner tint per row, optional
)
```
- `table table-striped table-hover align-middle`, wrapped in `table-responsive`
- First column left-aligned, all others right-aligned with tabular-nums
  (matches `pdf_lib.make_table` — keep the two skills consistent)
- Cells accept inline HTML: `'<span class="text-success">+50%</span>'`

## Callouts

```python
from html_lib import callout

callout("info",    "<strong>Finding.</strong> ...")
callout("warning", "<strong>Caveat.</strong> Confounds, coverage bias...")
callout("success", "<strong>Pass.</strong> ...")
callout("danger",  "<strong>Fail.</strong> ...")
```

## Nav-tabs and accordion (need the JS bundle — include_js=True, the default)

```html
<ul class="nav nav-tabs" role="tablist">
  <li class="nav-item"><button class="nav-link active" data-bs-toggle="tab"
      data-bs-target="#tab1" type="button" role="tab">Summary</button></li>
  <li class="nav-item"><button class="nav-link" data-bs-toggle="tab"
      data-bs-target="#tab2" type="button" role="tab">Detail</button></li>
</ul>
<div class="tab-content">
  <div class="tab-pane fade show active" id="tab1" role="tabpanel">...</div>
  <div class="tab-pane fade" id="tab2" role="tabpanel">...</div>
</div>

<div class="accordion">
  <div class="accordion-item">
    <h2 class="accordion-header">

              data-bs-target="#why">Why?</button>
    </h2>
    <div id="why" class="accordion-collapse collapse"><div class="accordion-body">...</div></div>
  </div>
</div>
```

## Theming

- Dark (default): `build_head(title, theme="dark")`
- Light: `build_head(title, theme="light")`
- **Light/dark toggle ships on every page by default** (the 🌓 button,
  top-right): flips `data-bs-theme`, persists the choice in
  `localStorage["html-lib-theme"]` (restored before first paint — no flash),
  and re-themes Chart.js charts and Mermaid diagrams automatically. Opt out
  with `build_head(theme_toggle=False)`; do not remove it otherwise.
- Custom overrides go in `extra_css="..."` — use Bootstrap CSS variables
  (`var(--bs-body-bg)`, `var(--bs-tertiary-bg)`, `var(--bs-border-color)`,
  `var(--bs-secondary-color)`) so overrides work in both themes.

## Print CSS

`html_lib` already hides the 🌓 toggle, the diagram ⛶ buttons and the zoom
overlay when printing. If you add interactive controls, also wrap them in:

```css
@media print { .no-print { display: none !important; } }
```

## Fonts

System stack — no webfont fetch, so offline rendering is instant:
`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
(already applied globally by Bootstrap's reboot).

## Engineering rules

- **Compute, don't hardcode** — every number in the HTML comes from data.
- **NaN guard** — filter `v != v` before any `max()`/`mean()`; a single NaN
  poisons whole charts ("the NaN trap").
- **"no data", never an exception** — missing data renders a muted note.
- `grep -c ">nan<" report.html` must be `0` before shipping.
